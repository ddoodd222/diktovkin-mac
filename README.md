# Диктовкин

Голосовой ввод для macOS. Живёт в строке меню. Говоришь — он печатает.

Распознавание идёт на компьютере через whisper.cpp на Metal. Звук никуда не уходит.

**[Скачать для macOS](https://github.com/ddoodd222/diktovkin-mac/releases/latest/download/Diktovkin.dmg)** · [о программе](https://ddoodd222.github.io/diktovkin-mac/) · бесплатно, macOS 13+, Apple Silicon · модель уже внутри, интернет не нужен

## Что умеет
- **Горячая клавиша** (по умолчанию ⌃⌥Пробел): первое нажатие включает запись, второе останавливает. Текст встаёт в то окно, которое было активным.
- **Состояние в строке меню**: микрофон — ждёт, красный микрофон со счётчиком — пишет, волна с процентами — распознаёт.
- **Плашка у курсора**: пока идёт запись, рядом с курсором мыши висит счётчик, точка на нём растёт от громкости. Отключается в меню.
- **Свои звуки**: на начало и на конец записи отдельно — тишина, системный звук или свой файл.
- **Модель на выбор**: сжатая small (190 МБ), обычная small (488 МБ) и medium (1,5 ГБ). Язык по умолчанию русский.

## Сборка
```bash
./build.sh
```
Скрипт сам скачает исходники whisper.cpp (один раз, тег `v1.8.2` в `.build/`), соберёт
их вместе с ggml и Metal, скомпилирует Swift, положит `dist/Диктовкин.app`,
скопирует в `/Applications` и запустит.

Всё, что лежит в `models/ggml-*.bin`, уезжает внутрь приложения. Тогда установщик
самодостаточен: на первом запуске сеть не нужна. Папка `models/` не под гитом.

`./build.sh --no-install` собирает только в `dist/` и не трогает установленное
приложение. Это спасает права доступа: после обычной установки macOS спрашивает их заново.

Ни brew, ни cmake, ни Xcode не нужны — хватает Command Line Tools. Шейдеры Metal
лежат внутри бинарника и компилируются при первом запуске: компилятора `metal`
в Command Line Tools нет.

После каждой пересборки macOS заново спросит доступ к микрофону и «Универсальный
доступ» — это нормально, подпись без сертификата разработчика меняется при каждой сборке.

## Проверка распознавания из терминала
```bash
/Applications/Диктовкин.app/Contents/MacOS/Diktovkin --file запись.wav ru
```
Печатает распознанный текст и тайминги: сколько ушло на подъём модели и на распознавание.

## Где что лежит
- модели — `~/Library/Application Support/Diktovkin/models/`
- настройки — `defaults read ru.tokarev.diktovkin`

## Известная особенность мака
В Command Line Tools остался лишний старый файл `module.modulemap`, из-за которого
компилятор Swift падает. `build.sh` обходит это виртуальной подменой. Лечится навсегда
одной командой:
```bash
sudo rm /Library/Developer/CommandLineTools/usr/include/swift/module.modulemap
```
